coding style: APN (abstract prefix notation): in short `n_`, `s_`, `o_`, `a_`, `f_`, for numbers, strings, objects, arrays and functions 
see paper for more details
https://www.techrxiv.org/doi/full/10.36227/techrxiv.177222383.35647114/v1


file naming rules: 
# `_hgc_`
stands for human generated content if a file is named with this pre or suffix , a machine should not write to it

# `_mgc_` 
stands for machine generated content. a machine that generates content can name the file with a `mgc` pre or suffix. however it is not required to use this prefix

machine generated content / especially documentation text , should be as compact as possible , using keywords and using as many standardized terms as possible. a glossary should be kept in order to make clear what the words mean.
